Akira chan, before Wednesday

Ten minutes on your office PC, any time before our 10 AM session. It lets Steven's side prepare your assistant on the machine remotely, so Wednesday is spent using Akira chan — not installing it.

What this does, plainly. It connects your PC to a private, isolated link that only Steven's laptop can reach — it can see nothing else, and your PC can reach nothing of his. Nothing else is installed at this step. It shows up in Settings → Apps as PAIA Connect (julien), and you can uninstall it there any time, including right after Wednesday.

Before you start

  • Do this on the Windows desktop at the office — the one Akira chan will live on.
  • You need to be able to click Yes on a Windows permission prompt (admin). If IT manages the PC and that's blocked, stop here and tell Steven — we'll plan around it.
  • The password for the download is in Steven's WhatsApp message to you.

The steps

1

Download

Download PAIA-Connect-julien.zip 62 MB

If the browser asks whether to keep it, keep it.

2

Extract

Open your Downloads folder, right-click the zip → Extract All… → Extract. Windows will ask for the password from the WhatsApp message.

Open the extracted folder PAIA-Connect-julien. Don't run it from inside the zip.

3

Run it

Right-click PAIA Connect.bat → Run as administrator → click Yes.

If Windows says "Windows protected your PC": click More info, then Run anyway. (It's not code-signed yet — that's all that warning means.)

4

Wait for "active"

A black window does its work for about a minute. Leave it open until a message says PAIA Connect is active — closing it early stops the install halfway. If it asks to restart, restart, then run step 3 once more; it picks up where it left off.

5

Send Steven the account name

The "active" message shows your Windows account name. Reply on WhatsApp with it (a screenshot is fine). That's the one thing we can't see from our side.
